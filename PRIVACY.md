# Chat Export — Privacy Policy

**Effective date:** 12 October 2026

## Overview

Chat Export is a Chrome extension that lets users copy or download conversations from Claude, ChatGPT, and Grok as Markdown files.

Chat Export is designed to process conversation content locally in the browser. The extension does not operate a server that receives or stores exported conversations.

## Information accessed

Chat Export accesses conversation content only when the user explicitly selects "Copy conversation" or "Download full chat".

To export a conversation, the extension may retrieve its content from the relevant AI service's conversation endpoint, the currently rendered webpage, or an embedded conversation payload.

When the extension popup opens, it reads the active tab's URL to determine whether the current page is supported.

Conversation content may contain personal information or other sensitive information that the user has included in their conversation.

## How information is used

Conversation content is used solely to generate a Markdown representation of the conversation requested by the user.

The resulting Markdown is held temporarily in the extension popup's memory while the popup is open. The extension does not persistently store conversation content.

When the user chooses to copy a conversation, the extension writes the requested content to the clipboard. When the user chooses to download a conversation, the extension creates a file for the user to save locally.

## Sharing and third parties

Chat Export does not upload exported conversation text to the developer or transmit it to an analytics, advertising, or other external server operated by the developer.

The extension does not sell conversation content or use it for advertising, profiling, or analytics.

Chat Export interacts with Claude, ChatGPT, and Grok to retrieve conversations from the services where those conversations already exist. Those services have their own privacy policies and data-handling practices.

## Data retention

The extension does not maintain a remote database of conversations or persistently store exported conversation content. Temporary data held in the popup is discarded when the popup is closed. Files or clipboard contents explicitly created by the user are under the user's control.

## Chrome Web Store Limited Use disclosure

Chat Export's use of information obtained from websites is limited to providing its single purpose: exporting a conversation that the user explicitly chooses to copy or download. Its use of such information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
